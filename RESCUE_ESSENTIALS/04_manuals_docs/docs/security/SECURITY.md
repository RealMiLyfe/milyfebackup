# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to:

**Email:** security@milyfe.os

We appreciate responsible disclosure and will:
- Acknowledge receipt of your report within 24 hours
- Provide regular updates on our investigation
- Work with you to understand the issue and its impact
- Coordinate disclosure timing when appropriate

## What to Include

To help us investigate quickly, please include:
- Type of issue (e.g., XSS, SQLi, auth bypass)
- Full description of the vulnerability
- Steps to reproduce
- Proof of concept or exploit code (if applicable)
- Impact assessment
- Any relevant logs or screenshots

## Scope

This policy applies to all code in the `RealMiLyfe/milyfe-os` repository and associated services.

## Preferred Languages

We prefer reports in English but will work with any language.

## Policy

We follow responsible disclosure practices and do not pursue legal action against good-fact security research.

## Bounty

While we don't currently offer a formal bug bounty program, we greatly appreciate community contributions to our security and may recognize significant contributions in our credits.

## Supported Versions

We provide security updates for the current stable release version of MiLyfe OS.
